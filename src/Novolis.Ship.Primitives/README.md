# Novolis.Ship.Primitives

Avalonia-free ship CAD helpers on top of `Novolis.Cad.Primitives` — pressure volumes, airlocks, hatch pressure fields (including vacuum-assisted / pressure-assist seals), and ship document metrics (`LOA` / beam / deck spacing).

## Install

```bash
dotnet add package Novolis.Ship.Primitives
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (net10.0).
