# Novolis.Ship.Topology

Builds a compartment adjacency graph from Cad walls/spaces/openings and classifies sealed pressure volumes versus vents to exterior.

## Install

```bash
dotnet add package Novolis.Ship.Topology
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (net10.0).
