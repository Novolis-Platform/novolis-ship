# Novolis.Ship.Structure

Avalonia-free structural plate specs, BOM lines, and outer-skin mass rollup for ship Cad documents.

Attaches to `.cadjson` document properties as `structure.material`, `structure.bom`, and `structure.mass`.

## Install

```bash
dotnet add package Novolis.Ship.Structure
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (net10.0).
