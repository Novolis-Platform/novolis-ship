# Novolis.Ship.Validation

Rule checks for ship Cad documents — personnel hatch clearances, airlock pairing, orphan openings, LOA envelope.

## Install

```bash
dotnet add package Novolis.Ship.Validation
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (net10.0).
